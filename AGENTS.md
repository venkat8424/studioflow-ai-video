## UI Implementation Guidelines

1. Read `DESIGN.md` before implementing frontend changes.
2. Review the relevant mockup in `.ai-mocks/`.
3. Match the approved mockup as closely as practical.
4. Follow the design tokens and interaction rules in DESIGN.md.
5. Do not modify files in `.ai-mocks/` unless explicitly requested.
6. Do not invent additional UI elements or redesign approved screens.
